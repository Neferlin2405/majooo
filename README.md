# Para Majo — Entre las Estrellas · Versión 5

## Cómo abrir

1. Descomprime el ZIP completo y abre `index.html` en Safari o Chrome.
2. Mantén la carpeta `assets/` junto al archivo `index.html` para escuchar y ver el video.
3. Para GitHub Pages, sube **index.html** y la carpeta **assets/** al repositorio, manteniendo su estructura.

## ¿Qué contiene?
- Tu fotografía real en la primera Polaroid y tres recuadros reservados.
- Dedicatoria disponible para escuchar sin imagen o ver en video 1080p dentro de la web.
- Archivo de audio M4A original extraído sin recodificación (AAC 320 kb/s).
- Video H.264 1080p/30 fps optimizado para carga web con el mismo audio original (sin recodificar).
- Música de fondo Julia al volumen reducido previamente al 40%, que se pausa al reproducir la dedicatoria.
- La sorpresa aparece solo al pulsar escuchar o ver, y puede alternarse de una forma a otra.

## Nota técnica
La versión ZIP es la más adecuada para publicarse en internet: el video se descarga al pulsar reproducir, no durante la carga de la portada. La alternativa HTML Todo Incluido pesa mucho más y puede tardar en abrirse en un teléfono.

Recuerda verificar los derechos de uso de la canción comercial antes de alojarla públicamente.
